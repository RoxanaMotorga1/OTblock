# OTblock

**Diagrams, built together.**

OTblock is a collaborative diagram editor that runs in the browser. Build
diagrams from shapes and arrows, invite teammates with a link, and edit the
same canvas at the same time. You can see who is connected, follow their
cursors and selections, and your work is saved on the server.

## Demo

### Editor

1. Drag a rectangle, an ellipse and a text shape from the palette onto the canvas.
2. Double-click a shape to edit its label inline, and change its fill color in the properties panel.
3. Connect two shapes with an arrow by dragging from a connection handle.
4. Multi-select, copy/paste and delete, then undo/redo all of it.
5. Save, reload the page and see the diagram restored. Export to JSON and import it back.

### Collaboration

1. Open a diagram, copy its share link and open it in a second browser window as a different user.
2. Both users appear in the connected users list with a name and color.
3. Each user sees the other's live cursor and current selection, highlighted in that user's color.
4. Both users edit at the same time (move, add, connect, edit labels) and the diagram stays identical in both windows, with no lost edits.
5. Take one user offline, edit, then reconnect. The changes merge.
6. Close all windows and reopen the link, or restart the server. The diagram is restored from the server.
